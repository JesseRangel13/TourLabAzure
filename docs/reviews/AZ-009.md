## 4. Architectural & Behavioral Observations

* **Zero-Trust Identity Architecture**:
  * In cloud configuration, connection strings for Azure SQL, Service Bus, and Azure Blob Storage omit embedded passwords or shared access keys, relying instead on `TokenCredential` / Azure AD Managed Identities.
* **Cryptographic Defense-in-Depth**:
  * Data Protection keys are wrapped by Key Vault encryption keys. Even if the underlying SQL database or Blob container were exposed, Data Protection key rings remain cryptographically protected by Key Vault.
  * Public key rollover allows publishing both active and previous public keys, enabling zero-downtime key rotation for JWT signing and token verification.
* **Database-Enforced Immutability**:
  * While application logic guards against overwriting confirmed receipt snapshots, SQL Server-level `DENY UPDATE` permissions on snapshot columns guarantee that even compromised worker processes cannot alter historical confirmation records.
