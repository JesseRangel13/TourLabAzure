## 4. Architectural & Behavioral Observations

* **Two-Tier Image Validation**:
  * Uploads are inspected first via fast magic-byte signature detection (JPEG `FF D8 FF`, PNG `89 50 4E 47 0D 0A 1A 0A`).
  * Validated streams then undergo full decoding via `SixLabors.ImageSharp` to verify exact pixel dimensions (up to 2048x2048), color spaces, and memory allocations, rejecting embedded script polyglots or corrupt compression blocks.
* **Self-Healing Background Recovery**:
  * Instead of exposing complex manual recovery endpoints, the hosted `ImageRecoveryWorker` continuously scans for intent records in `Pending` or `DeletePending` states exceeding lease timeouts.
  * If the Blob exists in Azurite, the worker transitions the row to `Ready`; if the Blob is absent, the intent is cancelled. Deleted blobs are purged asynchronously while retaining audit records in `ImageHistory`.
* **Private Container Access**:
  * No public blob URLs or container SAS tokens are leaked to the browser. Images are served via authenticated streaming through `/api/catalog/v1/tours/{tourId}/images/{imageId}/file`, enforcing active tour visibility for tourists and cache headers for browser performance.
