## 4. Key Architectural & Operational Highlights

* **Strict TLS with Trusted Root CA**:
  * Testing over HTTPS uses a locally generated Root CA (`CN=TourLab Azure Local CA`) imported into the current user's trust store. Chromium executes with `ignoreHTTPSErrors: false`, providing genuine end-to-end TLS verification without security downgrades.
* **Zero-Leakage CI Reporting**:
  * `Write-TestSummary.ps1` and `.github/workflows/ci.yml` implement a strict boundary: only `ci-summary.json` containing integer counts and booleans is published as a CI artifact. Raw process outputs, network traces, DOM snapshots, and credentials remain strictly local.
* **Non-Destructive Broker Testing**:
  * Instead of clearing or purging shared Service Bus queues, `BrokerSelection.cs` bounds message inspection to 64 items and abandons unrelated message locks upon completion. The dedicated isolated emulator on port 5674 allows complete lifecycle verification with zero impact on primary lab development resources.
* **Defensive Client State Architecture**:
  * The Angular client uses NGXS feature states with signal selectors and explicit session boundary interceptors. On receiving an HTTP 401 or user logout, all 8 state slices are cleared to initial state, preventing cross-user data leakage.
