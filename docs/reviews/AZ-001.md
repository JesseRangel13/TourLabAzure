## 3. Findings by Severity

### Finding 1: Docker Desktop Daemon Inactive (Low / Environmental Precondition for AZ-002)
* **Severity**: Low (Informational for AZ-001; Blocker for AZ-002)
* **Location**: Local development environment
* **Impact**: While AZ-001 requires only structure validation (`docker compose config`), AZ-002 requires real SQL Server integration testing. SQL Server and emulators cannot start until Docker Desktop is active.
* **Remediation**: Launch Docker Desktop and verify with `docker info` before beginning AZ-002 database migrations.

### Finding 2: Azure Functions Core Tools (`func`) Missing from PATH (Low / Environmental Precondition for AZ-008)
* **Severity**: Low (Informational for AZ-001; Blocker for AZ-008)
* **Location**: System PATH
* **Impact**: `Receipts.Functions` builds cleanly, but local host invocation requires Azure Functions Core Tools v4.
* **Remediation**: Install `azure-functions-core-tools@4` when approaching AZ-008.

### Finding 3: Local Lab CA Certificate Trust in Chromium (Low / Environmental)
* **Severity**: Low
* **Location**: Local certificate trust store / Chromium browser
* **Impact**: Playwright config correctly sets `ignoreHTTPSErrors: false` to uphold security invariant. The generated lab CA (`.local/certificates/ca.crt`) needs current-user trust approval before headless Chromium can load `https://localhost:9443` without certificate warnings.
* **Remediation**: Execute `scripts/Trust-LocalCa.ps1` in an elevated/interactive terminal session when executing browser UI end-to-end tests.
