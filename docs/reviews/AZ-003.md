## 4. Observations & Notes

* **Filtered Unique Index on `QuoteId`**:
  SQL Server by default treats multiple `NULL` values as duplicate entries in unique indexes. The model explicitly configures `.HasFilter("[QuoteId] IS NOT NULL")`, properly supporting multiple release tombstones where `QuoteId` is null.
* **Deterministic Decimal Precision**:
  Check constraints specify `CONVERT(decimal(38,0), [TotalAmountMinor]) = CONVERT(decimal(38,0), [UnitAmountMinor]) * [Participants]`, preventing integer overflow or floating point representation errors.
* **Process Liveness vs. Broker Activation**:
  Catalog event intents are safely recorded into the owned `Outbox` table. Broker publication and subscriber consumption remain properly scoped for AZ-004.
